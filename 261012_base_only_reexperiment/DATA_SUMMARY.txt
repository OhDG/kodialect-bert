검증 완료
- 34,213개 원본 JSON의 해시와 실제 추출 수량을 생성 시 확인
- 원본 학습/평가 코드 및 requirements 18개와 복사본의 SHA256 일치
- 전체 TSV와 corpus의 행, 레이블, 파일별 분할, 번역 쌍 검증 통과
- 분류 평가용 변경 문장 캐시의 문장과 지역 정렬 확인
- 전송 대상 42개 파일의 해시 기록: 4,944,167,319 bytes (4.60 GiB)
- run_all.py --check-only 통과; 토크나이저/모델 학습은 로컬에서 실행하지 않음

- server/translation/: 기존 260811 번역 코드 및 준비 데이터

서버 실행
1. server 폴더 전체를 복사 (Git으로 제외된 data와 results/changed_flags_cache.npz도 포함)
2. 기존 실험에 사용한 연구실 서버 환경 활성화
3. server 폴더에서 python run_all.py --check-only
4. 전송 후 전체 무결성 확인: python verify_bundle.py --full
5. python run_all.py
토크나이저 학습 -> 네 MLM 인코더 학습 -> 5개 시드 지역 분류 및 변경 문장 분석 -> 표준어 CLM 디코더 -> 5개 시드 번역 순서로 실행
처음 check-only에서 번역 인코더 PENDING은 정상이며, 앞선 지역 분류 실행에서 새 데이터로 생성한다.
