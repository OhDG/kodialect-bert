공통 전처리 정책
버전: common-dialect-text-v1-2026-10-12

목적
- 같은 원본 utterance에서 얻은 source_text를 토크나이저 학습, MLM,
  지역 분류, 방언에서 표준어로의 변환 입력에 공통 사용한다.
- 방언/표준어 대응쌍을 복원하되 방언 고유 문자와 의미 있는 내용을
  문자 허용목록으로 삭제하지 않는다. 기존 clean_base_text와 다른 실험 조건이다.
- 원천 JSON 파일은 수정하지 않는다. 공통 모듈은 문자열만 반환한다.

1. 정규화
- 양쪽 문자열에 NFKC 정규화와 공백 정규화(연속 공백류를 한 칸으로,
  앞뒤 공백 제거)를 동일하게 적용한다.
- NFKC는 호환 자모의 코드 포인트를 바꿀 수 있지만, 자모/옛한글을
  허용목록 밖이라고 삭제하는 단계는 없다. 영문, 한자, 숫자도 보존한다.

2. 방언/표준어 이중 전사
- 명확하고 중첩되지 않은 (A)/(B)에서 source 필드는 A, target 필드는 B를
  택한다. 두 필드는 각각 처리한다. JSON form 필드로 대체하지 않는다.
- 괄호와 슬래시 사이의 공백/줄바꿈을 허용하고, 주변 단어에 붙은 표기도
  처리하되 임의로 띄어쓰기를 추가하지 않는다.
- 한쪽이라도 한글/자모/옛한글이 있는 쌍을 이 규칙의 대상으로 삼는다.
  (x)/(y), x/(y), (x)/y처럼 비한국어인 표현은 수학/영문 표기일 수 있어
  보존하고 non_korean_parenthesized_slash_preserved 플래그를 기록한다.
- 한쪽이 빈 쌍, 잘린 대응쌍, 중첩되거나 연쇄된 대응쌍은 선택을 추측하지
  않고 ambiguous_transcription_pair로 해당 utterance 전체를 제외한다.
- 단독 괄호 안에 명확한 방언 대응쌍이 중첩된 경우도 해석을 추측하지 않고
  제외한다. 예: (설명 (방언)/(표준어) 내용).

3. 청취 불확실 표기에 대한 보수적 제외
- 두 겹의 여는 괄호로 시작하는 ((추정한 내용)), (()), 공백이 끼인
  ( ( 내용 ) ) 등을 어느 한쪽 필드에서라도 발견하면 해당 utterance를
  uncertain_transcription으로 모든 과제에서 공통 제외한다.
- 일부 구간만 지우면 source/target의 대응이 어긋날 수 있으므로, 이번
  재구축에서는 구간 삭제 대신 문장 단위 제외를 채택한다.
- 이는 연구용 정답 품질을 위해 이번에 채택한 보수적 정책이다.
  AI Hub 제주도 원천 자료의 모든 이중 괄호가 오류라는 판정이 아니다.
  수학적 중첩 괄호 같은 예외도 보수적으로 제외될 수 있으며 수량을 기록한다.

4. 근거가 확정되지 않은 표기
- 단독 괄호, 그 내용, 영문/수학 괄호를 보존하고 플래그를 기록한다.
- 단독 괄호가 불균형하더라도 방언 대응쌍이라는 증거가 없으면 보존하고
  unbalanced_standalone_parentheses_preserved로 표시한다.
- #, *, @, ~, 대괄호, 중괄호, 역슬래시 등은 일괄 삭제하지 않는다.
  관찰되는 표기는 해당 플래그와 카운터로 남긴다. 괄호 외 기호의 해석이나
  삭제로 이번 변경 범위를 확장하지 않는다. #를 모두 개인정보 마스킹이라고
  단정하지 않는다. 발화 주석의 의미는 자료/필드에 따라 다를 수 있다.
- 소스에 표준어만 택하거나 괄호 속 내용을 무조건 삭제하지 않는다.

5. 누락값과 반환 계약
- source가 없거나 빈 문자열/문자열 아닌 값이면 모든 과제에서 제외한다.
- source가 유효하고 target이 없거나 비어 있으면 source는 MLM/분류에
  사용하고 번역/표준어 디코더 코퍼스에는 포함하지 않는다.
- has_standard는 정제 후 유효한 target이 존재하는지를 의미한다.
- changed_raw는 원본 dialect_form/standard_form에 NFKC/공백 정규화만
  적용한 뒤 서로 다른지 비교한다. 한쪽이 없으면 False다.
- 주요 변경 문장 평가는 builder가 별도로 계산하는 changed_clean,
  즉 유효한 최종 source_text != target_text를 사용한다.
- 제외된 결과는 source_text='', target_text=None, has_standard=False,
  drop_reason에 이유를 담는다. changed_raw는 원본 비교값을 보존한다.
- stats는 정수 카운터, flags는 정렬된 고유 문자열 목록이다.
  플래그만 있다는 이유로 제외하지 않는다. drop_reason으로 판단한다.

구별할 사항
- form에 정상 이중 전사가 있는 것은 오류가 아니다.
- dialect_form/standard_form에 대응쌍이 남은 것은 입력/정답을 별도로
  쓰기 전에 해소해야 하는 표현이며, 이번 모듈에서 명확한 경우만 해소한다.
- 제외량과 유형은 빌드 결과로 보고한다. 이번 정제 후 문장 수와 성능을
  기존 전처리 실험과 동일한 데이터 조건이라고 표현하지 않는다.
