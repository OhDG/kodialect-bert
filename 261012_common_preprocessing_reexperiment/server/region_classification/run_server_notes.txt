지역 분류 서버 실행

로컬 데이터 구축과 검증이 끝난 server 폴더 전체를 연구실 서버로 옮깁니다.
server/bundle_ready.json이 completed: true로 생성되어 있어야 합니다.
현재 디렉터리에서 아래 순서로 실행합니다.

1. python run_server.py --check-only
   표준 라이브러리만 사용합니다. 학습 패키지나 GPU 없이 준비 파일 8개,
   분할 메타데이터(seed 42, 8:1:1, 누락 파일 0), 변경 문장 분석 캐시의 배열 목록,
   원본 코드 SHA256을 확인합니다. 로컬 구축기의 전체 행 검증을 다시 수행하는 명령은 아닙니다.

2. python run_server.py
   원본 260819 실행기의 토크나이저 학습, MLM, 지역 분류, 결과 집계를 그대로 호출합니다.
   원본의 01_prepare_data 단계만 준비 파일 검증으로 대체하여 서버에서는 원본 JSON을 읽지 않습니다.
   토크나이저 4개, 분류 시드 13/21/42/87/100 및 모든 학습 기본값을 유지합니다.
   중단 후 같은 명령을 실행하면 원본 실행기의 완료 확인과 학습 재개 방식을 따릅니다.

3. python run_server.py --analyze-only
   전체 지역 분류 완료 후 실행합니다. 로컬에서 만든 results/changed_flags_cache.npz와
   서버의 예측 결과를 원본 step6으로 분석합니다. 원본 기본값인 clean 기준을 사용합니다.
   이번 캐시의 clean은 공통 전처리 후 방언 입력과 표준어 정답의 비교이며,
   이전 문자 삭제 규칙으로 다시 정제한 결과가 아닙니다.
   원본 step6이 캐시의 문장 순서와 평가 TSV, 예측 레이블의 정렬을 검증합니다.

이 래퍼는 --overwrite, --smoke, --reuse_mlm_from 및 학습 조건 변경 인자를 받지 않습니다.
원본 실행 파일을 직접 실행하거나 변경 문장 분석에 --rebuild를 추가하지 않습니다.
원본 파일은 수정하지 않았으며 원본 코드 해시 목록은 상위 폴더에 보관합니다.
기존 실험의 outputs, cache, dialect_bert_tokenizer를 이 디렉터리에 복사하지 않습니다.

연구실의 기존 실험 Python/CUDA 환경을 사용합니다. requirements_260819.txt는 일부 추가
의존성만 포함하며 torch, transformers, datasets, tokenizers, accelerate 등 전체 환경 명세가 아닙니다.
데이터 양이 바뀌므로 epoch당 학습 횟수와 시간, 새 학습 빈도로 계산되는 클래스 가중치 숫자는
달라집니다. 계산 방식과 학습 하이퍼파라미터는 원본 그대로입니다.
